# sloticon

Slot digests and icon fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/sloticon/

## Install / run

```bash
git clone https://github.com/theworker02/sloticon.git
cd sloticon
node src/cli.js
node --test
```
